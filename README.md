Project: UrbanGIS: St. John’s Spatial Data Project

This project focuses on extracting and analyzing geospatial data for St. John’s, Newfoundland and Labrador (NL), Canada. Using QGIS and OpenStreetMap (OSM), I extracted roads, buildings, and property features for a defined area of interest.
The project demonstrates skills in geospatial database integration, spatial analysis, and urban data visualization, which can support urban planning, infrastructure management, and risk assessment.

Objectives:
Define a specific area of interest within St. John’s, NL.
Extract roads, buildings, and property data from OpenStreetMap using QuickOSM.
Organize and save the extracted features into shapefiles/GeoPackages.
Visualize and style layers in QGIS for better interpretation.
Prepare the dataset for potential use in spatial analysis, impact studies, and decision-making.

Tools & Technologies:
QGIS – GIS analysis and visualization
QuickOSM Plugin – extract OSM data (roads, buildings, amenities, etc.)
OpenStreetMap – open geospatial dataset source
GeoPackage / Shapefile – storage and export formats

Results:
Generated clean geospatial layers of roads, buildings, and properties for St. John’s.
Built a structured dataset ready for:
Urban planning and zoning studies
Infrastructure mapping and analysis
Risk and impact assessments
Educational and research purposes

Applications:
City Planning – visualize road and building networks for development projects.
Academic Use – practice geospatial data handling and visualization.
Transportation Studies – analyze accessibility and connectivity.
Disaster Management – assess infrastructure exposure in risk scenarios.
